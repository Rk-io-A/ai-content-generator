# AI Content Generator + SEO Blog ✍️

**Full Stack AI Content Generator & SEO Blog Platform**

Generate blog posts with AI, optimize for SEO, and publish. Perfect portfolio project.

## 📁 Structure

```
ai-content-generator/
├── frontend/          # Next.js 14 + Tailwind CSS
├── backend/           # FastAPI + OpenAI ready
├── .gitignore
└── README.md
```

## ✨ Features

- 🤖 AI Blog Post Generator (topic → full article)
- 📊 SEO Score & Meta suggestions
- 📝 Blog list + detail pages
- 🔐 JWT Authentication
- 🎨 Clean modern UI
- 📡 Ready for OpenAI / Gemini API

## 🛠️ Tech Stack

| Layer     | Technology                        |
|-----------|-----------------------------------|
| Frontend  | Next.js 14, TypeScript, Tailwind  |
| Backend   | FastAPI, SQLAlchemy, Pydantic     |
| AI        | OpenAI API (optional)             |
| Database  | SQLite / PostgreSQL               |

## 🚀 How to Run

### Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
→ http://localhost:3000
